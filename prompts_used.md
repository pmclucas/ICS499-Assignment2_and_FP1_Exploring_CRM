## Best Prompts

This prompt kept the results very technical and seemingly removed much of the standard filler text.
```
Prompt:
You are a software consultant assigned to investigate Customer Relation Management (CRM) systems and provide recommendations to a modern software development company considering CRM adoption.
```

Including this in the prompt saved a lot of time converting to markdown format.
```
Prompt:
Provide response in markdown code format.
```

This was surprisingly helpful.  Sometimes the AI failed to convert to markdown in the initial prompt or would format it vastly different than other conversations.  Having it recognize how I was formatting the document and making the necessary adjustments saved a lot of time.
```
Prompt:
Convert the provided information to markdown code following the markdown formatting conventions previously established in this document.
```

Responses contained many more lists.  This made the information easier to digest quickly.
```
Prompt:
Format each response so it is easy to read and understand at a glance.
```

This allowed me to quickly cross reference the information provided.  Performance varied depending on the model used.  Links were not always correct but the information could typically be found by searching the internet with the reference information that was provided.
```
Prompt:
Include sources for the response (not to be included or limited by word count restrictions), including the related category.
```



## AI Effectiveness Analysis

Discuss:

### What AI did well
```
AI did an excellent job at reformatting and converting plaintext into markdown code.  It also performed surprisingly well with very few constrains included in the initial prompts.  It did an excellent job at providing accurate summaries of large bodies of work.
```

### What AI struggled with
```
I noticed that it sometimes picked up information from websites that were not entirely relevant to the question.  Providing examples of trusted sources in the prompt may yield better results depending on the subject matter.

Having the AI convert the response to markdown code in the initial prompt sometimes resulted in incoherent responses.  Doing the conversion in a separate prompt worked much better.

Requesting links for the material referenced often resulted in dead links when using older models.  Newer models seem to provide more accurate results but it was not 100%.

It sometimes struggled with accuracy when producing very specific information such as historical dates.  After reviewing the sources referenced it appears that it was pulling from both well established trusted sources and commercial websites serving as advertisements for products which were often incorrect.
```

### What information required validation
```
Specific information like dates or time periods needed to be validated.  Informating like pricing also needed to be checked.  I assume this is because it is referencing cached material.
```

### What surprised you
```
At first this was a bit of a struggle because I was using older less expensive models to conserve tokens.  However, once I found a prompt format that was working well for me, using the more expensive models did yield much useful results.

Also, I noticed that including some guard rails in the prompt did improve the usefulness of the response, but the quality dropped off drastically if I put too many constraints.
```

### What would you do differently next time
```
For next time I want to spend more time planning out how to approach prompting the AI.  Doing some research on what works well with the various models would have been very helpful as the responses varied drastically depending on which one I was using.  Some prompts that had worked well for me in the past were seemingly too restrictive for this task.
```

### Would you trust AI for software research?

Explain why or why not.

```
I feel that AI does an excellent job doing general research and providing a broad overview of what types of software are available.  I feel that if there are specific software needs that need to be met, that a person still takes the time to validate that the information is correct before making a decision.  AI should be treated as a tool to make our jobs easier and not a replacement for human understanding and reasoning.  
```
